## 🚀 Featured Projects

### 🔐 [tamper-evident-audit-log](https://github.com/deekshithburra/tamper-evident-audit-log)

An **append-only audit log service** that makes any modification, deletion, or reordering of records detectable — while still supporting the retention and field-level redaction that real compliance systems require.

- **SHA-256 hash chain** linking every record to the one before it, with a `/audit/verify` endpoint that pinpoints the first broken record
- **Salted per-field Merkle commitments** so sensitive fields can be redacted without breaking the chain
- **Independently verifiable exports** checked offline by a verifier with no database or service dependencies
- **Least-privilege roles, object-level scoping, credential rotation, and per-credential rate limiting**
- Documented with architecture notes, a threat model, and six ADRs
